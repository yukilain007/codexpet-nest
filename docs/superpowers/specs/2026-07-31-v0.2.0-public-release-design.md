日期：2026-07-31  
状态：已获用户确认  
目标版本：v0.2.0

## 目标

为“夏以昼”和“沈星回”两套独立桌宠建立面向普通用户的正式下载入口，并补齐适合小红书传播的中文说明与 AI 辅助安装流程。

交付完成后，用户应当能够：

- 从固定的 GitHub Release 页面下载正确角色和系统对应的安装包。
- 按中文说明在 macOS 或 Windows 上完成安装、首次启动和卸载。
- 把一段现成指令复制给具备本机操作能力的 AI，让 AI 识别系统、下载正确文件、校验哈希并协助安装。
- 在系统出现安全确认时亲自决定是否继续；AI 不关闭或绕过系统保护。
- 直接复制精简文案到小红书，向读者说明下载和安装方法。

## 不在本次范围内

- 不重新构建桌宠、不修改角色素材或运行逻辑。
- 不制作独立下载网站或短链接服务。
- 不提供会关闭 Gatekeeper、SmartScreen、Defender 等保护的一键脚本。
- 不对现有提交改写历史。
- 不包含或提交用户现有的 `pnpm-workspace.yaml` 未提交改动。

## Release 资产

正式 Release 上传六个安装包和一个校验文件。

### macOS 14+，Apple Silicon

```text
CodexPet Nest Xia Yizhou_0.2.0_aarch64.dmg
CodexPet Nest Shen Xinghui_0.2.0_aarch64.dmg
```

### Windows 10/11，x64

推荐使用 NSIS 安装包：

```text
CodexPet Nest Xia Yizhou_0.2.0_x64-setup.exe
CodexPet Nest Shen Xinghui_0.2.0_x64-setup.exe
```

MSI 作为备用：

```text
CodexPet Nest Xia Yizhou_0.2.0_x64_en-US.msi
CodexPet Nest Shen Xinghui_0.2.0_x64_en-US.msi
```

校验文件：

```text
SHA256SUMS.txt
```

发布前重新计算所有安装包的 SHA-256，并要求结果与 `SHA256SUMS.txt` 完全一致。

### `docs/AI-INSTALL-zh-CN.md`

提供普通用户可直接复制给 Codex、Claude 等电脑助手的安装口令，并同时写出 AI 应遵守的执行规范。

AI 流程固定为：

1. 询问并确认要安装“夏以昼”“沈星回”或两个都安装。
2. 只读检测操作系统、版本与 CPU 架构。
3. 若平台不受支持，停止并解释原因。
4. 从 `yukilain007/codexpet-nest` 的 `v0.2.0` Release 下载对应安装包和 `SHA256SUMS.txt`。
5. 在安装前计算 SHA-256；不匹配则删除损坏下载并停止。
6. macOS 挂载 DMG 并把应用复制到“应用程序”；Windows 默认运行 `-setup.exe`，只有 EXE 失败时才建议 MSI。
7. 遇到 Gatekeeper、SmartScreen、管理员授权或其他系统确认时暂停，让用户查看并亲自确认。
8. 不运行关闭安全保护、移除隔离属性或加入杀毒白名单的命令。
9. 启动桌宠并向用户报告安装结果和应用位置。

文档同时提供两个版本的复制口令：

- 简洁版：适合小红书读者直接复制。
- 严格版：包含来源限制、哈希校验和安全停止条件。

该文案不夸大兼容性，不把 Windows 自动化测试描述为实体设备人工实测。

## 安全与失败处理

- 下载来源固定到 `https://github.com/yukilain007/codexpet-nest/releases/tag/v0.2.0`。
- 文档不提供通用“下载最新版本”指令，避免 AI 在未来选到不兼容资产。
- 所有自动安装步骤先校验哈希。
- 不要求用户关闭系统安全功能。
- GitHub 上传或校验失败时保留为草稿，不公开不完整 Release。
- 公开后发现文档问题可编辑 Release 内容；安装包问题则先转回草稿或标注暂停下载，再上传修复后的新版本，不静默替换校验值。

## 验收标准

- 仓库首页和两份中文安装文档中的链接可用。
- Release 标签指向包含最终中文说明书的提交，该提交以 `1fe14e7c52913a3f244c22b1f846da275f27b0cc` 为构建基线，二者之间没有影响安装包的代码改动。
- Release 包含六个安装包和 `SHA256SUMS.txt`，无 `.DS_Store`。
- Release 中的六个安装包哈希与校验文件一致。
- 手动说明能让非技术用户明确选对角色、系统和安装包。
- AI 安装口令明确要求识别平台、固定来源、校验哈希、在安全提示处暂停。
- 文档没有包含密钥、令牌、本机私有路径或虚假的测试结论。
- 用户现有的 `pnpm-workspace.yaml` 改动未被纳入任何提交。
