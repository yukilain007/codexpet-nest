# CodexPet Nest v0.2.0 Public Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task with checkpoints.

**Goal:** Publish the existing Xia Yizhou and Shen Xinghui standalone desktop pets with a stable GitHub v0.2.0 Release, clear Chinese installation documentation, and a safe copy-paste AI installation workflow suitable for Xiaohongshu readers.

**Architecture:** Keep the already-built binaries unchanged. **Tech Stack:** Markdown, Git, GitHub CLI (gh), SHA-256 (shasum), existing Tauri standalone release bundle.

- Products are exactly 夏以昼 and 沈星回.
- macOS target: macOS 14 or later on Apple Silicon; asset suffix _aarch64.dmg.
- Windows target: Windows 10 or 11 on x64; recommend -setup.exe, retain MSI as backup.
- Installers come from /Users/yuki/Downloads/CodexPet-Nest-Standalone-v0.2.0-20260716/ and must not be rebuilt or renamed locally; GitHub normalizes spaces to dots in public asset names.
- Binaries were built from 1fe14e7c52913a3f244c22b1f846da275f27b0cc; final release tag may include documentation-only commits after that baseline.
- Release contains exactly six installers plus SHA256SUMS.txt; never upload .DS_Store.
- Public SHA256SUMS.txt uses the six normalized Release basenames and is sourced from docs/SHA256SUMS-v0.2.0.txt.
- AI instructions pin the repository and v0.2.0, verify SHA-256, and stop for human review at OS security prompts.
- AI instructions never disable Gatekeeper, SmartScreen, Defender, quarantine, or other system protections.
- Preserve the unrelated pnpm-workspace.yaml modification; never stage it.
- Do not rewrite existing commit history.
