# CodexPet Nest｜夏以昼 & 沈星回桌宠

两只可以独立安装、同时运行的本地桌宠：夏以昼和沈星回。它们会根据鼠标位置转向、回应点击和拖动，也会在等待或长时间不操作时做出自己的小动作。

## 下载

请从固定的 GitHub Release 下载：
https://github.com/yukilain007/codexpet-nest/releases/tag/v0.2.0

| 角色 | macOS（Apple Silicon） | Windows（x64，推荐） |
| --- | --- | --- |
| 夏以昼 | CodexPet Nest Xia Yizhou_0.2.0_aarch64.dmg | CodexPet Nest Xia Yizhou_0.2.0_x64-setup.exe |
| 沈星回 | CodexPet Nest Shen Xinghui_0.2.0_aarch64.dmg | CodexPet Nest Shen Xinghui_0.2.0_x64-setup.exe |

Windows 的 _en-US.msi 是同角色的备用安装包。macOS 版本要求 macOS 14 或更高，并且是 Apple Silicon（M1/M2/M3/M4 等）；Windows 版本要求 Windows 10/11 x64。

## 快速安装

1. 在 Release 页面选择想要的角色。
2. 按自己的系统下载对应文件：macOS 选 .dmg，Windows 优先选 -setup.exe。
3. 安装后启动应用；首次遇到系统安全提示时，先核对文件名和 SHA-256，再由你本人确认是否打开。

完整步骤见 [中文安装说明](docs/INSTALL-zh-CN.md)。想让电脑助手代为下载和安装，可以复制 [AI 安装口令](docs/AI-INSTALL-zh-CN.md)。发帖时可直接使用 [小红书文案](docs/XIAOHONGSHU-POST-zh-CN.md)。

## 有什么好玩

- 鼠标靠近时会转向注视，支持 16 个方向。
- 单击、连续点击、拖动、挥手、跳跃和失败反馈。
- 等待时会有专属反应，长时间不操作会触发自主动作。
- 夏以昼和沈星回有不同的互动节奏和对话。
- 两个角色使用独立应用，可以分别安装，也可以同时运行。

## 隐私与安全

独立版在本机运行，不读取 Codex 状态，不依赖 Codex Desktop，也不安装全局鼠标钩子。当前安装包未做 Apple 公证或商业代码签名，因此 macOS 和 Windows 首次启动可能显示来源或发布者提醒；请只从上面的 Release 下载，并先核对 SHA256SUMS.txt。

如需卸载、校验文件或排查打不开的问题，请查看完整中文安装说明。
